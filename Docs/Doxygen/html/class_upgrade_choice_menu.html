◆ IsPermanentLevel()

bool UpgradeChoiceMenu.IsPermanentLevel ( int level)

Dice si al acabar este nivel toca elegir permanente. Toca en los niveles 3 y 6, pero solo si todavia no tiene las que corresponden a ese nivel: en el 3 se puede tener como mucho 1 y en el 6 las 2. Asi si ya consiguio una en el 3 de otra partida, al volver al 3 elige temporal y la segunda llega en el 6. En el 9 (o si ya las tiene todas) sale una temporal normal.

Parámetros
levelNivel que se acaba de terminar.
Devuelve
True si toca permanente.
