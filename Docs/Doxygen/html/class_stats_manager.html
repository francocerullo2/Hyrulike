Descripción detallada

Guarda todas las estadisticas del jugador: daño, vida, velocidad, las mejoras y los datos de la partida. Pasa de una escena a otra (DontDestroyOnLoad) para no perder nada al cambiar de nivel. Los valores base no se tocan; las mejoras se suman en los metodos de abajo (MaxHealth, Damage...).
